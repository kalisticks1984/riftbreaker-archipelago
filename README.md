# The Riftbreaker - Archipelago

An Archipelago integration for The Riftbreaker: **open campaign, story campaign and survival**. It has two halves:

| Part | Path | Output |
|---|---|---|
| Game mod (Lua + data overrides, the game's local mod loader) | `mod/` | `mods/Archipelago/` in the game folder |
| AP world (Python, with the client) | `apworld/riftbreaker/` | `riftbreaker.apworld` |
| Shared data | `apworld/riftbreaker/data.json`, `mod/lua/archipelago/ap_data.lua` (generated by `tools/gen_data.py`) | read by both halves |

## Build

```
python -I tools/extract_data.py "<Riftbreaker>" <data_dir>   # research trees, campaign graph, difficulties, survival maps, localization
python -I tools/gen_data.py <data_dir> .                     # mod data overrides + data.json + ap_data.lua
python -I tools/gen_checks_md.py                             # CHECKS.md
python -I tools/build.py --release --install                 # dist/, RiftbreakerAP-<version>.zip, install locally
```

IDs are keyed by name, so the same research shares one ID in every mode. Research takes the first of the open-tree
index, `+10000+` the story index and `+20000+` the survival index (open IDs match v0.3). Biomes are `+1100+i`,
filler `+1200+i`, progressive groups `+2000+i`, builds `+30000+i`, story missions `+31000+i` and survival minutes
`+32000+minutes`, all over 7720000. Regenerate only after a game update changes a tree.

## What it changes

| Feature | How |
|---|---|
| Modes | The mod overrides all three research trees and detects the mode from the campaign (`campaign_mode_open` / campaign type). The slot's mode is in the inbox; a different mode is refused with a HUD warning |
| Checks | Research (all non-free nodes), builds (`FindService:FindEntitiesByBlueprint`), story missions (`CampaignService:GetMissionStatus == MISSION_STATUS_WIN`), open biome arrivals, survival time (the mod's own timer in campaign data). Done builds and missions are remembered in campaign data |
| Rewards become items | `research_awards` stripped from non-free nodes in `research_tree_open_campaign.rt`, `research_tree.rt` and `research_tree_survival.rt` (hidden flags cleared, the story's 11 story-critical locks kept); items arrive via `PlayerService:AddGlobalAward` |
| Progressive items | `<base>_lvl<N>` families (plus a bare `<base>` node as level 1): 62 groups (58 in survival); copy k grants level k |
| Biome items | The open campaign's auto-unlock chain (`logic_or_2 -> logic_wait_1` in `open_campaign_main.logic`) is cut. Biome items call `CampaignService:UnlockBiome` |
| Research labels | The client scouts every location on connect and writes `mods/Archipelago/gui/archipelago_localizations.csv` (item, receiver, classification). The game reads it at startup |
| Near-instant research | `reserach_science_factor` ("Research time factor", default 1) set to 0.01 on every `DifficultyDef`; costs unchanged |
| Goal | Campaign data `global.arcology_assembly_complete` / `global.prime_rift_complete` == "true"; survival: timer >= `DifficultyService:GetMissionDuration()` |
| Energy Link | `ap_deposit` / `ap_withdraw` log `EL_DEPOSIT/EL_WITHDRAW <seq> <resource> <amount>`; the client updates `EnergyLink{team}` (withdraw = `add -x`, `max 0`, refund the remainder) and returns grants in the inbox. Sequence numbers are persisted per session, so nothing is applied twice |
| Co-op | The autoexec only runs on the host (`is_server`); rewards go to every player (`AddGlobalAward` per player) |
| Tracker | Client tab and `/tracker` evaluate every check with the apworld's own `Logic`; the inbox carries a one-line summary for the in-game `ap_tracker` command |

## Bridge (no networking in the game's Lua)

| Direction | Channel |
|---|---|
| game -> client | `Documents/The Riftbreaker/exor_logs.txt`, lines `[AP] HELLO / MODE / BOUND / MISMATCH / CHECKS / CHECK / BIOME / SURVIVE / GOAL / RECEIVED / EL_DEPOSIT / EL_WITHDRAW` |
| client -> game | `<game>/archipelago/inbox.lua` (`return { session, connected, player, mode, survival_map, energy_link, energy, items, labels, grants, tracker }`), read with `loadfile` every 2 s |

A campaign is bound to the first `<seed>:<slot>` that connects (campaign data `archipelago.session`). Other slots get
`MISMATCH` and nothing is applied.

## Game facts this depends on (verified against the game binary)

- Local mods must be **folders** in `<game>/mods/`. `Exor::ExternalContentUserMods` mounts `.zip` files too, but only
  reads a `*.manifest` (keys `author`, `homepage`, `version`, `game_version`, `tags`) from folders. Zipped local mods
  show as "unknown" / incompatible.
- `lua/*_autoexec.lua` runs at startup; `is_server`, `RegisterGlobalEventHandler`, `MissionService:AddGameRule` work there.
- Research is enabled only while the player owns a building with `limit_name "communications_hub"` (native
  `IsResearchEnabled`). The `ap_hub` console command places one for testing.
- Lua 5.1 with `io`/`os` removed; `loadfile` reads real paths relative to `bin/` and re-reads changed files.
- Archipelago 0.6.7's `CommonContext` never sets `seed_name`; the client takes it from `RoomInfo`.
